# Curso Java con BEDU

## Curso de Java Standar 

### 🧩Introducción
 En ese curso logramos desarrollar nuestras habilidades con la ayuda del lengujae Java, aplicando la programación orientada a objetos (POO) como base para prender conceptos básico y avanzados, de igual manera que aprendemos sobre las estructuras de datos, manejo de archivos y las buenas prácticas de SOLID y el manejo de excepciones, todo lo anterior para lograr la escritura de un código limpio, escalable y ordenado.
Tomando en cuenta que lo anterior fue visto en una división de dos módulo los cuales nos dieron los conocimientos básicos sobre el lenguaje Java como se describira acontinuación.
